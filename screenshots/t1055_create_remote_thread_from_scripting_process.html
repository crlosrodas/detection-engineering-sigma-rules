Detects a script interpreter or Office application creating a remote thread in another process
(Sysmon EID 8 CreateRemoteThread). Interpreters such as powershell.exe/pwsh.exe, wscript,
cscript and mshta, and Office apps such as winword/excel, have no legitimate reason to inject
threads into other processes, so this is a strong process-injection signal (e.g. PowerShell
Empire reflectively injecting a PE and running it via CreateRemoteThread). The rule keys on the
source process and is deliberately target-agnostic rather than hardcoding a specific target.
